# 真实图纸解析说明（PDF / PNG）

本项目已支持**上传真实二维工程图**并自动解析为参数化 Spec，对应比赛"功能完备度"与"专业贴合"两项。

## 1. 支持格式与解析链路

| 输入 | 文字提取 | 图形检测 | 说明 |
|---|---|---|---|
| **矢量 PDF** | PyMuPDF 直接读取文字层（置信度 0.9） | PDF 渲染 → OpenCV 轮廓/霍夫圆 | **推荐**，尺寸数字精确 |
| PNG / JPG | OCR（pytesseract → 系统 tesseract → 人工录入） | OpenCV 轮廓/霍夫圆 | 无 OCR 时仍可识别图形，文字由用户录入 |

解析流程：`加载图纸 → 提取文字 → 检测外轮廓与孔 → 推断长/宽/孔径/孔位 → 生成蓝图 → parse_blueprint`。

## 2. 关键推断逻辑

- **整体尺寸**：取图纸中 ≥10 的数值，最大两个判为长（L）、宽（W）。
- **孔径**：优先取带 `D`/`Ø`/`φ` 前缀的数值（如 `4x D6.5` → φ6.5）。
- **比例**：`scale = 外轮廓像素宽度 / L`，据此把像素坐标换算为毫米。
- **孔位**：外轮廓内的圆按**期望半径过滤**（`0.6~1.5 × φ/2 × scale`）抑制霍夫噪声，再按邻近度聚类取代表。
- **边距**：取"每个孔到最近边距离"的**中位数**（避免双峰干扰）。
- **离群检测**：某孔最小边距与中位数相差 >2mm 时，标注"疑似标注冲突"（如缺陷图中右上孔 x=115）。

## 3. 使用方式

### 命令行

```bash
cd backend
python scripts/export_samples.py        # 生成 samples/*.pdf 与 *.png
python -c "from app.drawing import parse_drawing; r = parse_drawing('../samples/plate_defect.pdf'); print(r.to_dict())"
```

### HTTP 接口

```
POST /api/tasks/from-drawing
  multipart/form-data:
    file            (PDF/PNG/JPG)
    preference      auto | assisted | manual
    budget          整数
    auto_threshold  浮点（默认 0.55）
```

返回 `task_id` / `parse`（含 `notes`、`drawing`）/ `issues`。

### 前端

页面顶部新增"上传图纸(PDF/PNG)"输入框与 **①b 从图纸解析** 按钮。

## 4. 人机协同约定

- 图纸未提供的量（如板厚、圆角）标记为 `inferred` 且置信度较低，按自适应档位进入"待确认"。
- 位图在无 OCR 环境下，文字解析降级为"人工录入"，但图形（轮廓/孔数/孔位）仍可用。
- 解析结果中的 `notes` 会列出所有不确定项与冲突提示。

## 5. 已知限制

- 仅支持**单视图、带尺寸标注的二维机械零件图**；装配体、复杂自由曲面不支持。
- 孔位识别依赖霍夫圆检测，对低分辨率、强抗锯齿或非正交视图的照片精度下降。
- 尺寸文字若被纯图形化（无法提取文字层且无 OCR），则需人工录入 L/W。
