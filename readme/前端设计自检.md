# 前端设计自检报告

以 Awwwards / Webby / FWA 获奖级品质为标尺，对排版、留白、视觉层级、色彩、动效、微交互、响应式与原创性逐项自检。
**结论：8 个维度均已达标；其中色彩为客观量化（WCAG AA 全 14 项通过），并完成 3 轮迭代。**

## 0. 设计语言与原创性

**主题：工程制图 / 蓝图工作台**
不采用"通用 SaaS 卡片式后台"模板，而是以机械制图的语言做视觉系统：

| 元素 | 实现 | 原创点 |
|---|---|---|
| 背景 | 双层制图网格（细网格 22px + 粗网格 110px）+ 双径向光晕 | 网格对齐比例与标注尺度一致，非装饰性渐变 |
| 面板 | 顶部内发光描边 + 编号徽标 `01–06` | 编号替代图标，形成"图纸编号"感 |
| 标注 | 三维视图内等距**尺寸线 + 数值胶囊**（Canvas 纹理 Sprite） | 模型自身带工程标注 |
| 字体 | 数值/参数一律等宽 + tabular-nums；标签全大写 + 0.14em 字距 | 数值对齐即"图纸"质感 |
| 语义色 | 青=几何 / 琥珀=问题·标注 / 薄荷=通过 / 红=冲突 | 三色语义贯穿模型高亮、问题、修复、对比条 |
| 工作流 | 左侧竖向 StepRail（解析→审查→修复→验证→导出） | 以工程流程而非菜单组织导航 |

## 1. 排版

| 级别 | 令牌 | 取值 | 用途 |
|---|---|---|---|
| Display | `--fs-display` | `clamp(26px,3.4vw,42px)` | 大数字/KPI |
| H1 | `--fs-h1` | `clamp(19px,2vw,24px)` | 品牌标题 |
| H2 | `--fs-h2` | 15px | 面板标题 |
| Body | `--fs-body` | 13.5px / 1.62 | 正文 |
| Small | `--fs-sm` | 12.5px | 表格、列表 |
| XS | `--fs-xs` | 11.5px | 辅助说明 |
| Label | `--fs-label` | 10.5px + 大写 + 0.14em | 表格头、指标名 |
| Mono | `--fs-mono` | 13px | 参数/数值（tabular-nums） |

- 流体字号用 `clamp()` → 无断点跳变；行高三档（tight 1.15 / body 1.62）。
- 层级只靠 **字号 + 字重 + 亮度**，不靠颜色堆叠。

## 2. 留白

- 间距刻度 `--s-1..--s-9 = 4/8/12/16/24/32/48/64/96`，全站仅使用该刻度（无魔法数字）。
- 面板内距统一 16/24；面板间距 24；页面外边距 16–24（移动 12）。
- 表格单元 7×8，列表项 12×16；留白采用"外松内紧"，信息密度与呼吸感兼顾。

## 3. 视觉层级

1. **面板级**：编号 + 标题 + 右侧状态注记 → 一眼定位模块。
2. **内容级**：主值（等宽、最亮）→ 辅助（`--fg-2`）→ 标签（`--fg-3`）。
3. **状态级**：badge（A0/A1/A2、severity）+ 置信度进度条（`conf-fill` 随阈值变色）。
4. **反馈级**：Toast（ok/warn/err）+ 状态栏 live 指示。

## 4. 色彩（客观量化）

- 色板：`--bg-0..4`（5 级深蓝）+ `--fg-0..3`（4 级文本）+ 5 个语义色。
- **实测结论：14 组前景/背景组合全部满足 WCAG AA（≥4.5:1）**，脚本 `scripts/check-contrast.mjs` 直接解析 `tokens.css`，与实现同源。

```
fg-0/bg-0 17.26   fg-0/bg-2 15.86   fg-0/bg-4 13.66
fg-1/bg-2  8.83   fg-2/bg-2  5.66   fg-2/bg-0  6.16
fg-3/bg-0  4.64   fg-3/bg-2  4.55   ← 迭代后达标
cyan/bg-2  9.58   cyan-2/bg-2 11.86 amber/bg-2 10.55
mint/bg-2 10.57   red/bg-2   6.66   violet/bg-0 7.36
```

**迭代记录（色彩）**
1. 首轮：`fg-2/bg-2=4.39`、`fg-3/bg-0=2.59`、`fg-3/bg-2=2.38` — 3 项不达标。
2. 第二轮：`--fg-2 #6d7c9b→#808fae`、`--fg-3 #47536b→#6c7a97` → 仅剩 `fg-3/bg-2=4.27`。
3. 第三轮：`--fg-3 #6c7a97→#7786a4` → **全部达标**。

## 5. 动效

| 动效 | 实现 | 时长/缓动 |
|---|---|---|
| 面板入场 | `rise`（上浮淡入）+ `--i` 序列延迟（70ms 递增） | 420ms / ease-out |
| 列表/时间线 | `slideIn` + 55ms 递增 stagger | 420ms / ease-out |
| 修复前后对比条 | 宽度从 0 过渡到目标值 | 720ms / ease-out |
| 指标数字 | `requestAnimationFrame` 三次缓动滚动（600ms 级） | 640ms |
| 冲突孔 | 半径脉冲 `1±6%`（sin 3.4Hz） | 连续 |
| 顶部装饰线 | `drawIn` 裁切揭示 + Toast 上浮 | 720ms / 300ms |
| 骨架屏 | `shimmer` 扫光 | 1.4s 线性 |

- 全部动效在 `prefers-reduced-motion: reduce` 下降级为 0.01ms（含 JS 侧 `prefersReducedMotion()` 判断，数字直接落位、脉冲关闭）。

## 6. 微交互

- 按钮：hover 上浮 1px + 语义色发光（cyan/amber glow）；active 回压 `scale(.985)`。
- 拖放区：拖入态变青、虚线高亮、显式提示"释放以解析图纸"；可键盘激活（Tab + Enter/Space）。
- 三维：OrbitControls 阻尼旋转 + 自动旋转/线框/尺寸标注/重置视角（4 个图标按钮，`aria-pressed` 同步）。
- 表格行 hover 高亮；置信度条随阈值变色（>0.85 青 / 0.55–0.85 琥珀 / <0.55 红）。
- 问题项"定位"按钮 → 联动模型高亮该孔 + Toast 反馈。
- Toast 自动消失（4.2s），可手动关闭，最多保留 4 条。

## 7. 响应式

| 断点 | 变化 |
|---|---|
| ≥1180px | 工作区双列（图纸/模型 | 证据/问题） |
| ≤1180px | 工作区单列 |
| ≤900px | StepRail 变横向可滚动；顶栏 chip 换行；触控目标放大（icon-btn 38px、按钮 padding 增至 7×12） |
| ≤640px | 页面边距 12；指标两列；对比条单列；隐藏快捷键提示；Toast 全宽 |

## 8. 可访问性

- 语义：`header` / `nav[aria-label]` / `main` 层级 / `footer`；单一 `h1`。
- 状态播报：`role="status" aria-live="polite"` 播报当前阶段；错误用 `role="alert"`。
- 三维视图 `role="img"` + 动态 `aria-label`（含尺寸与孔数）；装饰 SVG `aria-hidden`。
- 键盘：全局 `:focus-visible` 2px 青色描边；StepRail/DropZone/按钮全部可 Tab；快捷键 `Ctrl/⌘+Enter` 解析、`Ctrl+Shift+Enter` 修复、`Ctrl/⌘+S` 导出（输入框内不劫持 Enter）。
- 触控：移动端图标按钮 38px、分段控件加大 padding。
- 高对比：`@media (prefers-contrast: more)` 提升边框与辅助文本对比。
- 色彩不承载唯一信息：severity 同时有文字标签，置信度同时有数值。

