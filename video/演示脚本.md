# 功能演示视频脚本（≤3 分钟）

> 录制建议：1280×720 以上，终端字体放大，鼠标轨迹清晰；旁白关键词上字幕。

| 时间 | 画面 | 讲解要点 |
|---|---|---|
| 0:00–0:15 | 封面 / 标题 | 作品名与一句话定位："从二维工程图到可验证的参数化三维模型。" |
| 0:15–0:40 | 展示 `samples/plate_defect.png` 图纸 | 这是一张带尺寸标注的机械板图纸，右上孔标注 x=115，与"边距 15"的尺寸链矛盾。 |
| 0:40–1:10 | 前端工作台：点击"从图纸解析" | 证据面板逐项给出置信度条与档位徽标（A0 自动 / A1 需确认）；顶部展示 τ_high / τ_low 阈值。 |
| 1:10–1:30 | 审查问题面板 | 检出 1 条 HIGH 问题：孔位 (115,65)，右边距 5 < 最小 12；证据与置信度可见。 |
| 1:30–1:50 | 三维视图 | Three.js 展示板与 4 孔，问题孔高亮为红色。 |
| 1:50–2:20 | 点击"执行修复" | 修复时间线逐条滑入：hole.x4 115 → 105（旧值划线、影响集标签）；状态徽标"回归通过"。 |
| 2:20–2:40 | 回归验证与最终状态 | 页面显示"最终状态 DONE / 剩余问题 0"；再次审查为空。 |
| 2:40–2:55 | 终端运行 `python scripts/evaluate_suite.py` | 展示汇总指标：检出率 1.00、修复成功率 1.00、预算达标率 1.00。 |
| 2:55–3:00 | 导出证据报告 | 点击"导出证据报告"：同时生成 SHA-256 证据包并校验通过；收尾一句话价值主张。 |

## 备用镜头

- 演示"拒绝修复"：把动图切换到 `manual` 或低置信场景，展示问题进入"待人工确认"队列。
- 演示"级联修复"：把 margin 改为 5，一次改参数触发 4 条孔位约束失败，Agent 依次修复。
- 演示测试：终端 `python -m pytest -q`，显示 44 passed / 1 skipped。
- 演示"修复前后对比"：滚动到面板 06，展示参数对比条（上绿=修复后 / 下红=修复前）与问题集变化。
- 演示设计自检：`cd frontend && npm run check:contrast`，输出"全部达标（WCAG AA）"。
- 演示三维交互：拖动旋转模型、脉冲高亮的冲突孔、切换线框/尺寸标注/自动旋转。
