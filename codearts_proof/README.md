## 关键排错记录（可直接作为 P4 素材）

以下均为开发过程中的真实故障与修复，建议逐条截图并配上 AI 对话：

1. **演示件坐标赋值 bug**：`hole.y2` 误设为 `W - margin`，导致 h2 与 h4 重合、孔间距为 0。测试 `test_clean_spec_has_no_issues` 暴露 → 修正为 `margin`。
2. **派生参数不传播**：修改 `margin` 后孔位未重算，级联测试失败 → 新增 `propagate.py`，按拓扑序重算派生参数（`expr` 表达式）。
3. **表达式求值变量名非法**：`plate.L` 含点号不能作为 Python 标识符 → 在受控命名空间中将 `.` 映射为 `_` 后求值。
4. **覆盖推导后残留 expr**：缺陷注入把参数改为观测值，却未清空 `expr`，重算时引用空环境报错 → 覆盖时同步清空 `expr` 与 `depends_on`。
5. **修复目标不是最小过线**：直接修复到"最小边距 12"会让孔停在 108，而非图纸意图的 105 → 修复时优先采用图纸声明的 `margin` 参数（证据融合）。
6. **esbuild 原生二进制不可执行**（0xC0000409）：vite 构建链路在本机不可用 → 改为**零构建前端**（Preact + htm + three，浏览器原生 ESM + importmap）。
7. **PIL 矩形坐标顺序**：y 轴反向导致 `y1 < y0` 报错 → 按 `(0, W) → (L, 0)` 顺序绘制。
8. **本地回环 socket 被禁用**（WinError 10051）：HTTP 冒烟测试无法运行 → 降级为文件系统校验，HTTP 测试改为显式开关。
